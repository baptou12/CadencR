# Registry test authority

The shared Rust CLI and its libraries are the only business implementation. The
portable Node suite tests orchestration and diagnostics through the actual executable;
it does not import a JavaScript validator, signer, packer, or publisher. Legacy
JavaScript names describe historical fixture origins only, never executable
authority or a runtime fallback.

## Run

```sh
# Source checkout: builds cadencr-cli through the worktree Rust wrapper.
pnpm --dir tooling/marketplace-registry test

# Copied registry: explicitly supply the separately verified released executable.
CADENCR_REGISTRY_TEST_CLI=/absolute/path/to/cadencr npm test

# Exhaustive implementation and real-process coverage (also in workspace tests).
pnpm rust -- test -p cadencr-registry-core -p cadencr-registry-publisher -p cadencr-cli
```

`tests/run.mjs` resolves/builds the CLI once in the parent before launching test
workers, passes its explicit path to every worker, and strips `NODE_TEST_CONTEXT`.
`launcher.test.mjs` proves one source build with an inert `pnpm` stub, explicit
binary forwarding, nested suite execution, and failure propagation.

A missing, non-executable, or failing CLI fails the suite. No optional skip or
JavaScript fallback is permitted. A source build is bounded to ten minutes; CLI
smoke processes to twenty seconds. Test calls remove GitHub credential variables
and use only local commands, never publication against a real API.

## Retained non-business checks

- `native-cli.test.mjs` executes the actual binary from a script-free registry and
  checks frozen service signing bytes, input retention and negative boundaries.
- `contribution-runtime-retention.test.mjs` tests wrapper state retention and
  exact argument forwarding using an inert subprocess, not a business fallback.
- Workflow/bootstrap suites test protected orchestration and released CLI trust.
- `check-metadata-expiry.test.mjs` invokes Rust `registry check-metadata-expiry`:
  relative healthy/default renewal/expired states, explicit warning thresholds,
  catalogs and both policy envelopes, malformed/unsafe/bounded inputs, and exact
  `--json` stdout report versus stderr failure contracts. Deterministic exact
  clock boundaries are in `registry-core/src/metadata.rs::reports_untrusted_expiry_at_exact_boundaries`;
  invalid dates/clock windows in `rejects_invalid_clock_window_shape_and_dates`.
- `metadata-cli.test.mjs` invokes Rust `validate-metadata` and
  `validate-submission`: valid standalone schema-2 provider/theme/tab documents,
  input retention, ownership/provenance mismatch, nested-variant rejection,
  malformed/missing/oversized/symlink inputs, and JSON success/error separation.
  No diagnostic calls JavaScript business code.
- Root `scripts/marketplace-registry.test.mjs` checks fixture byte identity,
  mandatory nested-suite execution and failure propagation.
