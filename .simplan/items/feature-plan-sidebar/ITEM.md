# Feature plan sidebar with phase viewer
- **Type**: ✨ Feature
- **Status**: 📋 BACKLOG
- **Description**: The plans of a feature should be visible on the right side of the feature page as a full page height list. Each phase should have a fixed width, be scrollable, and have a "fullscreen" button that opens a modal to see the whole phase. On each phase (both modal and sidebar), the phase status should be visible.
