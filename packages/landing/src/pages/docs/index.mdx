Cadence is a desktop IDE for agent-driven work. It runs locally, reads from your existing provider keys, and never pushes commits on your behalf.

## Install

Download the latest build for macOS or Linux from the [GitHub releases](https://github.com/rle-mino/cadence/releases/latest). Source and build-from-source instructions live in the [repository](https://github.com/rle-mino/cadence).

## First session

1. Open Cadence and pick a project folder.
2. Create a new session — Cadence will create a worktree and a branch for it.
3. Pick a harness (Claude Code, OpenCode) and start chatting.
