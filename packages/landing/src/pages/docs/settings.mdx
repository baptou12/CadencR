## Notification destinations

On macOS, the notch can show live agent activity, brief previews for completed turns and requests, and an attention-first conversation list. Hover to expand it; click a row to open that conversation.

**Always on** controls its presence between notifications. **Always animate** controls the compact logo's movement. macOS installs use the notch destination while preserving notifications that were explicitly disabled. Unsupported devices fall back to system notifications.

Paired browser/PWA clients can enable Web Push. Push depends on the host running and the device granting notification permission. The test notification exercises the system-notification path for diagnosis.

## Name new conversations your way

**Auto-naming** lets you select a naming model and edit its system prompt. The editor starts with the built-in instructions and offers a reset. Adjust the language, length, or naming conventions you want for new tasks.

The naming model is separate from the provider/model used for task prompts. New task conversations follow your last accepted manual prompt across projects, with conversation overrides taking priority.

## Storage maintenance

<DocScreenshot
  src={storageImage}

Background optimization deduplicates verified command output and moves pasted images into durable blob storage. Progress is visible and work can resume after interruption.

Storage also offers an opt-in **1–365 day** policy and a manual run to shorten long command output in inactive archived conversations. This policy does not delete conversations, messages, user text, or agent replies. Read the selected retention scope before running it.

## Provider and project preferences

Providers expose their own supported profiles, models, thinking levels, and access controls. Local connector registration requires a restart after changes.

Project settings hold task defaults such as accent, worktree setup, and Git context. Inspect the conversation's resolved controls when you need to know what its next prompt will actually use.
