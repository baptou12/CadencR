## Find the right conversations

Search by words from the conversation title or task, then use filters to narrow the grid. Adjust the per-row control for larger reading panes or more conversations on screen. The filter input can collapse when you want more room for the conversations themselves.

| Filter or action         | Use it for                                                                       |
| ------------------------ | -------------------------------------------------------------------------------- |
| Free text                | Find a title or task you remember                                                |
| Project/provider filters | Narrow a large workspace                                                         |
| `/pin:true`              | Keep pinned conversations in view                                                |
| `/exclude`               | Remove selected conversations from the current view; stale exclusions are pruned |
| Pin                      | Keep a conversation easy to reach from the sidebar as well                       |

The filter suggestions in the app are the reference for supported values. Use [Sidebar saved views](../sidebar/) when you want to return to a saved sidebar filter and presentation.

## Read status before opening everything

Provider branding is distinct from activity. A blue activity ring identifies a working agent; a green check marks a finished response with unread messages. Permission and question indicators give direct access to pending requests.

Linked conversations remain traceable through their parent/child relationships. A completed child and a completed parent are separate events; inspect the specific conversation that owns the result.

## Work from the grid

Each pane can show its conversation's stream and composer. You can read, answer a request, send a follow-up, or open the full workspace for files and Git. Keep the number of visible panes low enough that their content remains readable.

Pin only the conversations you expect to revisit. Pins are workspace-wide, so a pinned task remains available even when it belongs to another project.

## Keyboard navigation

Use the **Unified agent list** section of [Shortcuts](../shortcuts/) for grid navigation, pinning, filtering, and focus controls. The same key can perform a different action when a composer, editor, or Git pane has focus.
