## Find and open files

Use the file tree when you know the folder, or `Cmd/Ctrl+P` in the editor scope for quick open. Content search finds text across the project. Tabs and split panes let you keep related files visible.

File-and-line references such as `src/checkout.ts:6` in an agent reply can open that location directly. Auto layout can place the file beside the conversation. **Copy Path** copies the project-relative path from the active file or tree.

## Edit and inspect code

| Feature                              | Use it for                                                             |
| ------------------------------------ | ---------------------------------------------------------------------- |
| Git gutter and read-only diffs       | Inspect changed lines and compare revisions                            |
| Blame                                | See the commit responsible for a line                                  |
| Definitions, references, and symbols | Navigate code when its language server supports the operation          |
| Diagnostics and rename               | Inspect errors and perform supported symbol refactors                  |
| Formatting                           | Apply the configured language formatter and inspect any reported error |
| Language mode                        | Override detection for one file or persist a choice for its extension  |

Language tooling depends on available servers. The editor shows their status rather than assuming every language has identical features. Oversized files can open in read-only large-file mode.

Unsaved buffers are preserved across formatting and external file updates. Review the visible state before deciding whether to save or adopt an external change.

## Preview documents and diagrams

Markdown preview renders diagrams and sanitized HTML. Repository-relative images resolve from the document's project context, with visible loading and error states.

Opening an `.excalidraw` file launches the embedded diagram editor rather than raw JSON. It tracks dirty state, supports auto-save, and accepts `Cmd/Ctrl+S`.

## Use Neovim

Select Neovim in **Settings → Editor**. CadencR runs a real instance using your own configuration and plugins. Its file tree, quick-open navigation, and file-and-line references open in the active editor backend.

Neovim accepts keyboard and mouse input. If the process exits, use the restart control in the pane. Terminal and Neovim resolve the same configured font family and size, including Nerd Font glyphs. Configuration errors are shown without discarding an editor that is already running.

On touch platforms, the interface can fall back to the built-in editor where a modal terminal editor cannot be driven reliably.

## Split panes and shortcuts

Use [Shortcuts](../shortcuts/) for the editor and editor-buffer scopes. Editor and terminal split shortcuts have different default directions; check the active scope before using them.
