CadencR is built around a simple idea: **stop switching between tools while you work with coding agents**.

Version 0.8.0 brought everyday Git work into the workspace, from reviewing and staging changes to updating branches and resolving conflicts. **CadencR v0.9.0 connects that workflow to the Git cloud providers around it.**

## From local changes to the complete review

Connect GitHub or GitLab from CadencR and open the pull request or merge request attached to your conversation. The Git tab now brings together:

- check and pipeline status;
- unresolved review comments;
- inline code locations and changed files;
- review-thread selection and keyboard navigation;
- direct handoff of selected feedback to the agent.

The sidebar also surfaces proposal health and unresolved feedback, so you can see what needs attention before opening another browser tab.

This is not a separate cloud dashboard. It is the missing continuation of the workflow already inside CadencR:

**change → review → checks → comments → agent follow-up**

## Less context switching, faster review loops

Agent work does not end when the code is written. Checks fail, reviewers leave comments, and the next useful prompt often starts with information living on GitHub or GitLab.

CadencR v0.9.0 keeps that context beside the code and the conversation. Select the relevant feedback, send it to the agent, inspect the resulting changes, and return to the review without rebuilding the context by hand.
