01 · Stream

Your harness — finally readable.

Raw terminal output buries every signal under bash, grep, cat, head. Cadencr reinterprets the stream as it arrives. Tool calls become pills. File writes become inline diffs. Long outputs collapse until you ask for them.

Same agent. Same commands. Orders of magnitude more legible.

  • Inline diffs — Dracula syntax, +/- gutters, not walls of unified patch.
  • Tool-call pills — Bash, Grep, Read, Edit, Thinking. Click to expand.
  • Per-message model tag — never guess which agent said what.
  • Context meter in the status bar so you see the window filling.

02 · Worktrees

One feature — four agents in parallel.

Every session gets its own git worktree, so each agent works on its own branch in its own checkout. Run Claude Code and OpenCode on the same ticket at once, compare their diffs, keep the one you like.

When you're ready, merge locally. Cadencr never pushes on your behalf.

  • Auto worktree — new session, new branch, new working copy.
  • Parallel agents — let them race on the same ticket.
  • Session switcher — ⌘1 through ⌘9.
  • Clean teardown — archive a session, the worktree folds away.
03 · Git

Git stays where you can see it.

Agents don't edit in place — they land commits. Cadencr shows the graph, the staged diff, and the pending message before anything ships. You review, edit the message, commit.

Or raise autonomy to High and let it run. Either way, the history stays yours.

  • Per-session branch with auto-generated names you can rename.
  • Commit previews before every tool-group lands.
  • Stash & checkout from the keyboard, no terminal detour.
  • Graph view of sessions × branches.

04 · Terminal

A real terminal, next to the agent.

Every session gets a PTY rooted at its own worktree. Use it for the things the agent shouldn't — ssh, dev servers, ad-hoc scripts.

Split the pane with ⌘\. The terminal and the agent see the same filesystem, in real time.

  • One PTY per session, rooted at the worktree.
  • Split view — agent left, terminal right, or stacked.
  • xterm.js, true color, correct scrollback, correct cursor.
  • Branch-aware prompt — always know which checkout you're in.
05 · Autonomy

Three dials — pick your comfort.

Agents are powerful. You're the one who has to maintain the code afterwards. Every project picks how much leash to give.

Low
Ask before commit.
Every tool call surfaces in the stream. Every commit waits for your approval. For code you deeply care about.
confirm · bash, edit, write
Medium
Manual continue.
Agent runs tools freely. Stops at each plan boundary and waits for "Continue." The default, and a good one.
auto · bash, grep, read  ·  confirm · edit, write
High
Full auto.
Let it cook. Commits land on the session branch. Review the diff when you come back. For sandboxes and side projects.
auto · everything · still reviewable
