## Context

Read the `.simplan/items/` directory to see existing items. Each subdirectory is an item slug containing an `ITEM.md` file (metadata) and a `PLAN.md` file (the plan).

## Configuration

Check `.simplan/config` for settings (key=value format). Relevant setting:
- `commit_plan=true` - If set, commit `.simplan/` changes after code commits

## Task

Generate a `ralph.sh` bash script that runs each phase of a planned item autonomously using Claude Code in a loop — one phase per iteration, fresh context each time.

### Arguments
- `$ARGUMENTS` may contain:
  - Item slug (optional - auto-selects if not provided)

### Steps

1. **Select item**:
   - If slug provided: use that item (must be `PLANNED` or `IDLE`)
   - If no slug:
     - Read all `.simplan/items/*/ITEM.md` files
     - First: Look for any item with status `IN_PROGRESS` (continue it)
     - If none: Pick the first item with status `PLANNED` or `IDLE` (alphabetical by slug)
   - If no eligible items exist, tell user to run `/item:plan` first

2. **Parse the plan**: Read `.simplan/items/<slug>/PLAN.md`
   - Extract the total number of phases
   - Extract the "Execution Steps" table if present (step groupings)
   - Note which phases are already complete (✅) vs pending (⬜ or 🔄)
   - Extract completion conditions if present

3. **Ask user about mode**:
   - First, check if sandbox mode is available:
     - `.simplan/sandbox.Dockerfile` must exist
     - `.simplan/config` must contain `commit_plan=true`
   - Use **AskUserQuestion**:
     - "How should the ralph loop run?"
       - "Interactive" (description: "You watch Claude work live. After each phase, review the changes, then Ctrl+C to end Claude and start the next iteration. Safe — you stay in control.")
       - "Sandbox (autonomous)" — **only show this option if both conditions above are met** (description: "Runs in a Docker container. Code is cloned inside, work happens on a sandbox/<slug> branch, pushed after each phase. Uses --dangerously-skip-permissions safely inside the container.")

4. **Write `ralph.sh`** to `.simplan/items/<slug>/ralph.sh` with this structure:

```bash
#!/usr/bin/env bash
set -euo pipefail

# Ralph loop for: <item title>
# Item: <slug>
# Generated by simplan item:ralph
#
# Usage:
#   ./ralph.sh          # Run all remaining phases
#   ./ralph.sh --dry    # Show what would run without executing
#
# Ralph loop best practices (https://ghuntley.com/loop):
# - Fresh context per iteration (new claude process each phase)
# - One phase per loop — small, focused, bisect-safe
# - Progress tracked via plan file, not context window
# - Stops on failure so you can intervene

export SIMPLAN_RALPH=true

ITEM_SLUG="<slug>"
PLAN_FILE=".simplan/items/${ITEM_SLUG}/PLAN.md"
ITEM_FILE=".simplan/items/${ITEM_SLUG}/ITEM.md"
DRY_RUN="${1:-}"

# Colors
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
NC='\033[0m'

log() { echo -e "${BLUE}[ralph]${NC} $1"; }
ok()  { echo -e "${GREEN}[ralph]${NC} $1"; }
err() { echo -e "${RED}[ralph]${NC} $1"; }
warn(){ echo -e "${YELLOW}[ralph]${NC} $1"; }

# Count completed and total phases
count_phases() {
  local total=$(grep -c '^### [⬜🔄✅] Phase' "$PLAN_FILE" || true)
  local done=$(grep -c '^### ✅ Phase' "$PLAN_FILE" || true)
  echo "$done/$total"
}

count_remaining() {
  grep -c '^### [⬜🔄] Phase' "$PLAN_FILE" || echo 0
}

log "Ralph loop for: <item title>"
log "Progress: $(count_phases)"
echo ""

PHASE_NUM=0
while true; do
  REMAINING=$(count_remaining)
  if [ "$REMAINING" -eq 0 ]; then
    ok "All phases complete!"
    break
  fi

  PHASE_NUM=$((PHASE_NUM + 1))
  log "=== Iteration $PHASE_NUM ($REMAINING phases remaining) ==="

  if [ "$DRY_RUN" = "--dry" ]; then
    warn "[dry run] Would execute next phase via claude"
    break
  fi

  <CLAUDE_COMMAND>

  ok "Iteration $PHASE_NUM complete. Progress: $(count_phases)"
  echo ""

  # Brief pause between iterations (context cooldown)
  sleep 2
done

ok "Ralph loop finished for '$ITEM_SLUG'"
ok "Final progress: $(count_phases)"
```

Replace `<CLAUDE_COMMAND>` based on user's choice in step 3:

**Interactive mode:**
```bash
  # Claude runs interactively — you see everything live.
  # When the phase is done, review the changes then press Ctrl+C to
  # end this Claude session. The loop will start the next phase.
  log "Press Ctrl+C when Claude is done to continue to the next phase."
  claude --allowedTools 'Read,Write,Edit,Bash(git *),Bash(npm *),Bash(npx *),Glob,Grep,Task' \
    --verbose "/item:exec $ITEM_SLUG" || true
```
Note: `|| true` so Ctrl+C (exit code 130) doesn't stop the loop.

**Sandbox (autonomous) mode:**

The generated script needs additional setup before the loop and cleanup after. The full script structure changes:

Before the loop (after the `count_remaining` function):
```bash
CONTAINER_NAME="simplan-sandbox-${ITEM_SLUG}"
SANDBOX_BRANCH="sandbox/${ITEM_SLUG}"
REMOTE_URL=$(git remote get-url origin)
CURRENT_BRANCH=$(git branch --show-current)

cleanup() { docker rm -f "$CONTAINER_NAME" 2>/dev/null; }
trap cleanup EXIT

log "Building sandbox image..."
if [ "$DRY_RUN" = "--dry" ]; then
  warn "[dry run] Would build: docker build -t simplan-sandbox -f .simplan/sandbox.Dockerfile ."
else
  docker build -t simplan-sandbox -f .simplan/sandbox.Dockerfile .
fi

log "Starting sandbox container..."
if [ "$DRY_RUN" != "--dry" ]; then
  docker run -d --name "$CONTAINER_NAME" \
    -v "$HOME/.claude:/home/sandboxuser/.claude:ro" \
    simplan-sandbox tail -f /dev/null

  log "Cloning repo inside container..."
  docker exec "$CONTAINER_NAME" git clone --branch "$CURRENT_BRANCH" "$REMOTE_URL" /workspace/repo
  docker exec -w /workspace/repo "$CONTAINER_NAME" git checkout -b "$SANDBOX_BRANCH"
fi
```

The `<CLAUDE_COMMAND>` for sandbox mode:
```bash
  docker exec -w /workspace/repo "$CONTAINER_NAME" \
    claude -p "/item:exec $ITEM_SLUG" \
      --dangerously-skip-permissions \
      --verbose \
    2>&1 | tee ".simplan/items/${ITEM_SLUG}/ralph-phase-${PHASE_NUM}.log"

  EXIT_CODE=${PIPESTATUS[0]}

  if [ $EXIT_CODE -ne 0 ]; then
    err "Phase execution failed (exit code: $EXIT_CODE)"
    err "Check log: .simplan/items/${ITEM_SLUG}/ralph-phase-${PHASE_NUM}.log"
    err "Fix the issue, then re-run ./ralph.sh to continue"
    exit 1
  fi

  # Push sandbox branch after each phase
  log "Pushing sandbox branch..."
  docker exec -w /workspace/repo "$CONTAINER_NAME" \
    git push origin "$SANDBOX_BRANCH" --force-with-lease

  # Copy plan file from container to track progress on host
  docker cp "$CONTAINER_NAME:/workspace/repo/$PLAN_FILE" "${PLAN_FILE}.sandbox-tmp"
  cp "${PLAN_FILE}.sandbox-tmp" "$PLAN_FILE"
  rm -f "${PLAN_FILE}.sandbox-tmp"
```

Replace `<slug>` and `<item title>` with actual values.

5. **Make it executable**:
   ```bash
   chmod +x .simplan/items/<slug>/ralph.sh
   ```
